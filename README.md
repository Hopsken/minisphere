# alto-network

A minimal, modern TypeScript project using pnpm, tsx, Vitest, Oxlint, Oxfmt, and Ultracite.

## Commands

```sh
pnpm start          # Run once
pnpm dev            # Run in watch mode
pnpm test           # Run tests once
pnpm test:watch     # Run tests in watch mode
pnpm typecheck      # Type-check without emitting files
pnpm lint           # Lint with Oxlint
pnpm format         # Format with Oxfmt
pnpm check          # Run type-checking, tests, linting, and formatting checks
pnpm fix            # Format and auto-fix with Ultracite
```
